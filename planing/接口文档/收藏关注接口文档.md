## 3. 统一封装返回结果

### 3.1 成功返回

后端**未**对成功响应做统一封装。接口成功时，直接返回对应 Schema 序列化后的 JSON，HTTP 状态码通常为 `200`（部分写操作为 `201`/`204`）。

### 3.2 错误返回

所有错误响应均由全局异常处理器统一封装，结构如下：

```json
{
  "code": <HTTP状态码>,
  "message": "错误描述",
  "detail?": "可选的详细错误信息"
}
```

| 场景 | HTTP 状态码 | `message` | 说明 |
|------|------------|-----------|------|
| 参数校验失败 | `422` | 请求参数校验失败 | 附 `detail: [...]` 具体字段错误 |
| 业务逻辑错误 | `400` / `401` / `403` / `404` | 视具体接口而定 | 如用户名已存在、权限不足等 |
| 数据库异常 | `500` | 数据库异常，请稍后重试 | — |
| 未预料异常 | `500` | 服务器内部错误 | 兜底，不暴露堆栈 |

**示例 — 参数校验失败：**

```json
{
  "code": 422,
  "message": "请求参数校验失败",
  "detail": [
    {
      "loc": ["body", "email"],
      "msg": "value is not a valid email address",
      "type": "value_error.email"
    }
  ]
}
```

**示例 — 权限不足：**

```json
{
  "code": 403,
  "message": "权限不足，需要超级管理员权限"
}
```

## 4. 认证说明

除 `POST /api/v1/users/login`、`POST /api/v1/users/register` 和 `POST /api/v1/users/refresh-token` 外，其余接口均需在请求头中携带访问令牌：

```
Authorization: Bearer <access_token>
```

令牌失效或缺失时，返回 `401`：

```json
{
  "code": 401,
  "message": "缺少认证令牌"
}
```

## 5. 单接口详细定义

### 5.1 收藏与关注管理

---

### POST `/api/v1/favorites/blog-posts/{post_id}`

- **功能**：收藏博客文章
- **认证**：登录用户
- **权限说明**：普通用户只能收藏已发布的文章；超级管理员可收藏任何文章（含草稿）。

#### Path 参数

| 名称 | 类型 | 必填 | 说明 |
|------|------|------|------|
| post_id | integer | 是 | 文章 ID |

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### 成功响应

- **状态码**：`201`
- **返回**：`FavoriteStatusResponse`

| 名称 | 类型 | 说明 |
|------|------|------|
| is_favorited | boolean | 收藏状态，固定为 `true` |

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 404 | 文章不存在或无权限查看 |
| 400 | 已收藏该文章 |
| 401 | 缺少认证令牌 |

### GET `/api/v1/favorites/blog-posts`

- **功能**：获取当前用户的博客文章收藏列表（分页）
- **认证**：登录用户
- **权限说明**：普通用户仅返回已发布的文章；超级管理员返回所有文章。

#### Query 参数

| 名称 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| skip | integer | 否 | `≥ 0`，默认 `0` | 跳过数量 |
| limit | integer | 否 | `1~100`，默认 `20` | 返回数量上限 |

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### 成功响应

- **状态码**：`200`
- **返回**：`BlogPostFavoriteListResponse`

| 名称 | 类型 | 说明 |
|------|------|------|
| items | `BlogPostListItem[]` | 收藏的文章列表（按收藏时间倒序） |
| total | `integer` | 收藏总数 |

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 401 | 缺少认证令牌 |
| 422 | 请求参数校验失败 |
