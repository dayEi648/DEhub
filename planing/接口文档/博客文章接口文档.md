| 方法 | 路径 | 功能简述 | 认证要求 |

| POST | `/api/v1/blog_posts/` | 创建博客文章 | 超级管理员 |

## 3. 统一封装返回结果

### 3.1 成功返回

后端**未**对成功响应做统一封装。接口成功时，直接返回对应 Schema 序列化后的 JSON，HTTP 状态码通常为 `200`（部分写操作为 `201`/`204`）。

### 3.2 错误返回

所有错误响应均由全局异常处理器统一封装，结构如下：

```json
{
  "code": <HTTP状态码>,
  "message": "错误描述",
  "detail?": "可选的详细错误信息"
}
```

| 场景 | HTTP 状态码 | `message` | 说明 |
|------|------------|-----------|------|
| 参数校验失败 | `422` | 请求参数校验失败 | 附 `detail: [...]` 具体字段错误 |
| 业务逻辑错误 | `400` / `401` / `403` / `404` | 视具体接口而定 | 如用户名已存在、权限不足等 |
| 数据库异常 | `500` | 数据库异常，请稍后重试 | — |
| 未预料异常 | `500` | 服务器内部错误 | 兜底，不暴露堆栈 |

**示例 — 参数校验失败：**

```json
{
  "code": 422,
  "message": "请求参数校验失败",
  "detail": [
    {
      "loc": ["body", "email"],
      "msg": "value is not a valid email address",
      "type": "value_error.email"
    }
  ]
}
```

**示例 — 权限不足：**

```json
{
  "code": 403,
  "message": "权限不足，需要超级管理员权限"
}
```

## 4. 认证说明

除 `POST /api/v1/users/login`、`POST /api/v1/users/register` 和 `POST /api/v1/users/refresh-token` 外，其余接口均需在请求头中携带访问令牌：

```
Authorization: Bearer <access_token>
```

令牌失效或缺失时，返回 `401`：

```json
{
  "code": 401,
  "message": "缺少认证令牌"
}
```

### POST `/api/v1/blog_posts/`

- **功能**：创建博客文章
- **认证**：超级管理员

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### RequestBody

`Content-Type: multipart/form-data`

| 名称 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| post_in | JSON 字符串 | 是 | — | 博客文章创建请求的 JSON 字符串 |
| file | file | 是 | 最大 20MB，后端自动压缩至 5MB 以下 | 封面图片文件，支持自动压缩 |

> **前端约定**：前端编辑器的封面图片**仅支持文件上传**，不暴露 `cover_image_url` 输入框。后端也不再接收 `cover_image_url` 作为请求入参；创建接口必须传 `file`，更新接口仅在上传新封面时传 `file`。

> 注：`post_in` 各字段如下：

| 名称 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| title | string | 是 | 1~64 字符 | 标题 |
| slug | string | 否 | 1~255 字符 | URL 友好标识；不传时根据 `title` 自动生成 |
| summary | string | 否 | — | 前端传入会被忽略；后端按正文长度自动生成或置空 |
| content_md | string | 是 | — | Markdown 正文 |
| category_id | integer | 是 | `≥ 1` | 分类 ID |
| tags | string[] | 否 | 默认 `[]` | 标签列表 |
| status | string | 否 | 仅允许 `draft` | 创建接口强制保存为草稿 |

> **前端约定**：同上，前端编辑器仅支持通过 `file` 字段上传封面图片，不提供 `cover_image_url` 输入。

#### 成功响应

- **状态码**：`201`
- **返回**：`BlogPostResponse`

| 名称 | 类型 | 说明 |
|------|------|------|
| id | integer | 文章 ID |
| title | string | 标题 |
| slug | string | URL 友好标识 |
| summary | string \| null | 摘要 |
| content_md | string | Markdown 正文 |
| cover_image_url | string \| null | 封面图 URL |
| category_id | integer | 分类 ID |
| category | `BlogCategoryBrief` | 分类信息 |
| tags | string[] | 标签列表 |
| status | string | `draft` / `published` |
| view_count | integer | 浏览量 |
| comment_count | integer | 评论数 |
| author | `UserBriefInfo` | 作者信息 |
| user_id | integer | 作者用户 ID |
| created_at | string(datetime) | 创建时间 |
| updated_at | string(datetime) | 更新时间 |

> `UserBriefInfo` 字段：id, username, avatar_url

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 403 | 权限不足，需要超级管理员权限 |
| 400 | 分类不存在 / slug 已存在 |
| 422 | 请求参数校验失败 |

### GET `/api/v1/blog_posts/{post_id}`

- **功能**：查看单篇博客文章详情（通过 ID）
- **认证**：登录用户

#### Path 参数

| 名称 | 类型 | 必填 | 说明 |
|------|------|------|------|

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### 成功响应

- **状态码**：`200`
- **返回**：`BlogPostDetailResponse`

在 `BlogPostResponse` 基础上增加：

| 名称 | 类型 | 说明 |
|------|------|------|
| prev_post | BlogPostListItem \| null | 上一篇文章 |
| next_post | BlogPostListItem \| null | 下一篇文章 |

`BlogPostListItem` 字段：

| 名称 | 类型 | 说明 |
|------|------|------|
| id | integer | 文章 ID |

| slug | string | URL 友好标识 |
| summary | string \| null | 摘要 |
| cover_image_url | string \| null | 封面图 URL |
| category_id | integer | 分类 ID |
| category | `BlogCategoryBrief` | 分类信息 |
| tags | string[] | 标签列表 |
| status | string | 文章状态 |
| view_count | integer | 浏览量 |
| comment_count | integer | 评论数 |
| author | `UserBriefInfo` | 作者信息 |
| user_id | integer | 作者用户 ID |
| created_at | string(datetime) | 创建时间 |
| updated_at | string(datetime) | 更新时间 |

> `UserBriefInfo` 字段：id, username, avatar_url

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 404 | 文章不存在或无权限查看 |

### GET `/api/v1/blog_posts/`

- **功能**：列出博客文章列表
- **认证**：登录用户
- **权限说明**：普通用户仅查询已发布的文章；超级管理员可通过 `include_unpublished=true` 查询未发布文章。

#### Query 参数

| 名称 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| skip | integer | 否 | `≥ 0`，默认 `0` | 跳过数量 |
| limit | integer | 否 | `1~100`，默认 `20` | 返回数量上限 |
| status | string | 否 | `draft`/`published` | 文章状态筛选 |
| category_id | integer | 否 | `≥ 1` | 分类 ID 筛选 |
| tag | string | 否 | — | 标签筛选 |
| q | string | 否 | — | 标题关键词搜索 |
| include_unpublished | boolean | 否 | 默认 `false` | 是否包含未发布文章（仅超管有效） |

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### 成功响应

- **状态码**：`200`
- **返回**：`BlogPostListResponse`

| 名称 | 类型 | 说明 |
|------|------|------|
| items | `BlogPostListItem[]` | 文章列表 |
| total | `integer` | 符合条件的文章总数（用于分页计算） |

`BlogPostListItem` 字段：

| 名称 | 类型 | 说明 |
|------|------|------|
| id | integer | 文章 ID |
| title | string | 标题 |
| slug | string | URL 友好标识 |
| summary | string \| null | 摘要 |
| cover_image_url | string \| null | 封面图 URL |
| category_id | integer | 分类 ID |
| category | `BlogCategoryBrief` | 分类信息 |
| tags | string[] | 标签列表 |
| status | string | 文章状态 |
| view_count | integer | 浏览量 |
| comment_count | integer | 评论数 |
| author | `UserBriefInfo` | 作者信息 |
| created_at | string(datetime) | 创建时间 |
| updated_at | string(datetime) | 更新时间 |

> `UserBriefInfo` 字段：id, username, avatar_url

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 422 | 请求参数校验失败 |
