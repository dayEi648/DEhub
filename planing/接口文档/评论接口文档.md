# 评论接口文档

## 1. 接口概览

### 1.1 评论管理

| 方法 | 路径 | 功能简述 | 认证要求 |
|------|------|---------|---------|
| POST | `/api/v1/comments/` | 新增评论 | 登录用户 |
| DELETE | `/api/v1/comments/{comment_id}` | 删除评论 | 评论作者或管理员 |
| GET | `/api/v1/comments/` | 分页查询评论列表 | 登录用户 |
| POST | `/api/v1/comments/{comment_id}/like` | 点赞评论 | 登录用户 |
| DELETE | `/api/v1/comments/{comment_id}/like` | 取消点赞评论 | 登录用户 |

## 2. 枚举与常量定义

| 常量/枚举 | 值 | 说明 |
|-----------|-----|------|
| 评论排序 `sort_by` | `"time"` | 按创建时间倒序 |
| | `"time_asc"` | 按创建时间正序 |
| | `"hot"` | 按点赞数倒序 |
| 默认分页 | `skip=0, limit=20` | 列表接口默认值，limit 上限 100 |

## 3. 统一封装返回结果

### 3.1 成功返回

后端**未**对成功响应做统一封装。接口成功时，直接返回对应 Schema 序列化后的 JSON，HTTP 状态码通常为 `200`（部分写操作为 `201`/`204`）。

### 3.2 错误返回

所有错误响应均由全局异常处理器统一封装，结构如下：

```json
{
  "code": <HTTP状态码>,
  "message": "错误描述",
  "detail?": "可选的详细错误信息"
}
```

| 场景 | HTTP 状态码 | `message` | 说明 |
|------|------------|-----------|------|
| 参数校验失败 | `422` | 请求参数校验失败 | 附 `detail: [...]` 具体字段错误 |
| 业务逻辑错误 | `400` / `401` / `403` / `404` | 视具体接口而定 | 如用户名已存在、权限不足等 |
| 数据库异常 | `500` | 数据库异常，请稍后重试 | — |
| 未预料异常 | `500` | 服务器内部错误 | 兜底，不暴露堆栈 |

**示例 — 参数校验失败：**

```json
{
  "code": 422,
  "message": "请求参数校验失败",
  "detail": [
    {
      "loc": ["body", "email"],
      "msg": "value is not a valid email address",
      "type": "value_error.email"
    }
  ]
}
```

**示例 — 权限不足：**

```json
{
  "code": 403,
  "message": "权限不足，需要超级管理员权限"
}
```

## 4. 认证说明

除 `POST /api/v1/users/login`、`POST /api/v1/users/register` 和 `POST /api/v1/users/refresh-token` 外，其余接口均需在请求头中携带访问令牌：

```
Authorization: Bearer <access_token>
```

令牌失效或缺失时，返回 `401`：

```json
{
  "code": 401,
  "message": "缺少认证令牌"
}
```

## 5. 单接口详细定义

### 5.1 评论管理

### POST `/api/v1/comments/`

- **功能**：新增评论
- **认证**：登录用户

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### RequestBody

| 名称 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| target_type | string | 是 | 1~32 字符 | 评论目标类型；支持 `blog_post`（博客文章）、`forum_reply`（论坛回复） |
| target_id | integer | 是 | `≥ 1` | 评论目标 ID |
| parent_id | integer | 否 | `≥ 1` | 父级 ID（博客场景为表层评论 ID，论坛场景为 reply ID；论坛场景下不传时后端自动填充为 `target_id`） |
| is_nested | boolean | 否 | 默认 `false` | 是否为嵌套回复 |
| nested_parent_id | integer | 否 | `≥ 1` | 嵌套回复所回复的里层/回复评论 ID；`is_nested=true` 时必填 |
| content | string | 是 | 最小 1 字符 | 评论内容（纯文本，不支持内嵌图片语法） |

#### 成功响应

- **状态码**：`201`
- **返回**：`CommentResponse`

| 名称 | 类型 | 说明 |
|------|------|------|
| id | integer | 评论 ID |
| target_type | string | 评论目标类型 |
| target_id | integer | 评论目标 ID |
| parent_id | integer \| null | 父级 ID |
| user_id | integer | 评论者 ID |
| content | string | 评论内容 |
| is_nested | boolean | 是否为嵌套回复 |
| nested_parent_id | integer \| null | 嵌套回复所回复的里层/回复评论 ID |
| likecount | integer | 点赞数 |
| is_liked | boolean | 当前登录用户是否已点赞 |
| created_at | string(datetime) | 创建时间 |
| user | CommentUserInfo | 评论者信息 |

`CommentUserInfo`：

| 名称 | 类型 | 说明 |
|------|------|------|
| id | integer | 用户 ID |
| username | string | 用户名 |
| avatar_url | string \| null | 头像 URL |

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 401 | 缺少认证令牌 |
| 400 | 不支持的评论目标类型 |
| 400 | 评论内容不支持内嵌图片（含 Markdown 图片语法 `![alt](url)` 和 HTML `<img>` 标签） |
| 404 | 评论目标不存在 |
| 422 | 请求参数校验失败 |

### DELETE `/api/v1/comments/{comment_id}`

- **功能**：删除评论（博客表层评论会级联删除其下所有里层回复与嵌套回复）
- **认证**：评论作者或管理员

#### Path 参数

| 名称 | 类型 | 必填 | 说明 |
|------|------|------|------|
| comment_id | integer | 是 | 评论 ID |

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### 成功响应

- **状态码**：`204`
- **返回**：无

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 404 | 评论不存在 |
| 403 | 权限不足 |

---

### GET `/api/v1/comments/`

- **功能**：分页查询评论列表
- **认证**：登录用户

#### Query 参数

| 名称 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| target_type | string | 是 | 1~32 字符 | 评论目标类型 |
| target_id | integer | 是 | `≥ 1` | 评论目标 ID |
| parent_id | integer | 否 | `≥ 0` | 父级 ID（为空不过滤，传 `0` 表示只查表层评论） |
| is_nested | boolean | 否 | — | 是否嵌套回复（为空不过滤） |
| nested_parent_id | integer | 否 | `≥ 1` | 嵌套父级 ID（为空不过滤） |
| sort_by | string | 否 | `time`/`time_asc`/`hot`，默认 `time` | 排序方式 |
| skip | integer | 否 | `≥ 0`，默认 `0` | 跳过数量 |
| limit | integer | 否 | `1~100`，默认 `20` | 返回数量上限 |

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### 成功响应

- **状态码**：`200`
- **返回**：`CommentListResponse`

```json
{
  "items": [CommentResponse],
  "total": 100
}
```

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 422 | 请求参数校验失败 |
