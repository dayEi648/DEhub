## 3. 统一封装返回结果

### 3.1 成功返回

后端**未**对成功响应做统一封装。接口成功时，直接返回对应 Schema 序列化后的 JSON，HTTP 状态码通常为 `200`（部分写操作为 `201`/`204`）。

### 3.2 错误返回

所有错误响应均由全局异常处理器统一封装，结构如下：

```json
{
  "code": <HTTP状态码>,
  "message": "错误描述",
  "detail?": "可选的详细错误信息"
}
```

| 场景 | HTTP 状态码 | `message` | 说明 |
|------|------------|-----------|------|
| 参数校验失败 | `422` | 请求参数校验失败 | 附 `detail: [...]` 具体字段错误 |
| 业务逻辑错误 | `400` / `401` / `403` / `404` | 视具体接口而定 | 如用户名已存在、权限不足等 |
| 数据库异常 | `500` | 数据库异常，请稍后重试 | — |
| 未预料异常 | `500` | 服务器内部错误 | 兜底，不暴露堆栈 |

**示例 — 参数校验失败：**

```json
{
  "code": 422,
  "message": "请求参数校验失败",
  "detail": [
    {
      "loc": ["body", "email"],
      "msg": "value is not a valid email address",
      "type": "value_error.email"
    }
  ]
}
```

**示例 — 权限不足：**

```json
{
  "code": 403,
  "message": "权限不足，需要超级管理员权限"
}
```

## 4. 认证说明

除 `POST /api/v1/users/login`、`POST /api/v1/users/register` 和 `POST /api/v1/users/refresh-token` 外，其余接口均需在请求头中携带访问令牌：

```
Authorization: Bearer <access_token>
```

令牌失效或缺失时，返回 `401`：

```json
{
  "code": 401,
  "message": "缺少认证令牌"
}
```

## 5. 单接口详细定义

### 5.1 论坛分区管理

### POST `/api/v1/forum_zones/`

- **功能**：创建分区
- **认证**：管理员及以上（`permission ≥ 1`）

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### RequestBody

| 名称 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| slug | string | 否 | 1~255 字符 | URL 友好标识；不传时根据 `zone_name` 自动生成 |
| zone_name | string | 是 | 1~64 字符 | 分区名称 |
| description | string | 否 | — | 分区描述 |
| manager_id | integer | 否 | `≥ 1` | 区主 ID；不传时默认将当前用户设为区主 |

#### 成功响应

- **状态码**：`201`
- **返回**：`ForumZoneResponse`

| 名称 | 类型 | 说明 |
|------|------|------|
| id | integer | 分区 ID |
| slug | string | URL 友好标识 |
| zone_name | string | 分区名称 |
| description | string \| null | 分区描述 |
| manager_id | integer | 区主 ID |
| manager | `UserBriefInfo` | 区主信息 |
| view_count | integer | 浏览量 |
| created_at | string(datetime) | 创建时间 |

> `UserBriefInfo` 字段：id, username, avatar_url

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 403 | 权限不足 |
| 400 | slug 已存在 / 指定的区主用户不存在或已注销 |
| 422 | 请求参数校验失败 |
