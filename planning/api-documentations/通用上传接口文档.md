## 3. 统一封装返回结果

### 3.1 成功返回

后端**未**对成功响应做统一封装。接口成功时，直接返回对应 Schema 序列化后的 JSON，HTTP 状态码通常为 `200`（部分写操作为 `201`/`204`）。

### 3.2 错误返回

所有错误响应均由全局异常处理器统一封装，结构如下：

```json
{
  "code": <HTTP状态码>,
  "message": "错误描述",
  "detail?": "可选的详细错误信息"
}
```

| 场景 | HTTP 状态码 | `message` | 说明 |
|------|------------|-----------|------|
| 参数校验失败 | `422` | 请求参数校验失败 | 附 `detail: [...]` 具体字段错误 |
| 业务逻辑错误 | `400` / `401` / `403` / `404` | 视具体接口而定 | 如用户名已存在、权限不足等 |
| 数据库异常 | `500` | 数据库异常，请稍后重试 | — |
| 未预料异常 | `500` | 服务器内部错误 | 兜底，不暴露堆栈 |

**示例 — 参数校验失败：**

```json
{
  "code": 422,
  "message": "请求参数校验失败",
  "detail": [
    {
      "loc": ["body", "email"],
      "msg": "value is not a valid email address",
      "type": "value_error.email"
    }
  ]
}
```

**示例 — 权限不足：**

```json
{
  "code": 403,
  "message": "权限不足，需要超级管理员权限"
}
```

## 4. 认证说明

除 `POST /api/v1/users/login`、`POST /api/v1/users/register` 和 `POST /api/v1/users/refresh-token` 外，其余接口均需在请求头中携带访问令牌：

```
Authorization: Bearer <access_token>
```

令牌失效或缺失时，返回 `401`：

```json
{
  "code": 401,
  "message": "缺少认证令牌"
}
```

## 5. 单接口详细定义

### 5.1 通用上传

---

### POST `/api/v1/uploads/image`

- **功能**：上传通用图片（前端限制 20MB，后端自动压缩至 5MB 以下），根据场景保存到不同 OSS 路径，返回可直接引用的 OSS URL
- **认证**：登录用户

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### Query 参数

| 名称 | 类型 | 必填 | 说明 |
|------|------|------|------|
| scene | string | 否 | 上传场景，可选值见下表，默认 `generic` |

#### RequestBody

`Content-Type: multipart/form-data`

| 名称 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | file | 是 | 图片文件（JPG/PNG/WebP），前端限制 20MB，后端自动压缩至 5MB 以下 |

#### 成功响应

- **状态码**：`200`

```json
{
  "url": "<oss_url>"
}
```

#### scene 枚举值

| 值 | 说明 | OSS 路径 |
|------|------|---------|
| `avatar` | 用户头像 | `users/avatar/{日期}/{uuid}.jpg` |
| `cover` | 博客封面 | `blog/covers/{日期}/{uuid}.jpg` |
| `generic` | 通用图片（默认） | `uploads/images/{日期}/{uuid}.jpg` |
| `forum_post` | 论坛帖子内嵌图片 | `forum/posts/{日期}/{uuid}.jpg` |
| `forum_reply` | 论坛回复内嵌图片 | `forum/replies/{日期}/{uuid}.jpg` |
| `comment` | 评论内嵌图片 | `comments/images/{日期}/{uuid}.jpg` |
| `chat` | AI 对话内嵌图片 | `chat/images/{日期}/{uuid}.jpg` |

> 说明：`comment` 场景仅表示上传能力；评论业务接口当前不支持内嵌图片，若在评论内容中提交图片语法会被后端拒绝。

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 401 | 缺少认证令牌 |
| 400 | 不支持的文件类型 / 未知的上传场景 |
| 413 | 图片压缩后仍超过 5MB 限制 |
| 422 | 请求参数校验失败 |
