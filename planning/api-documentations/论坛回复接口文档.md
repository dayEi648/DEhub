# 论坛回复接口文档

## 1. 接口概览

### 1.7 论坛回复管理

| 方法 | 路径 | 功能简述 | 认证要求 |
|------|------|---------|---------|
| POST | `/api/v1/forum_posts/{post_id}/replies` | 发表回复 | 登录用户 |
| GET | `/api/v1/forum_posts/{post_id}/replies` | 查询回复列表 | 登录用户 |
| DELETE | `/api/v1/forum_replies/{reply_id}` | 删除回复 | 作者本人、管理员或区主 |
| POST | `/api/v1/forum_replies/{reply_id}/like` | 点赞回复 | 登录用户 |
| DELETE | `/api/v1/forum_replies/{reply_id}/like` | 取消点赞回复 | 登录用户 |

## 3. 统一封装返回结果

### 3.1 成功返回

后端**未**对成功响应做统一封装。接口成功时，直接返回对应 Schema 序列化后的 JSON，HTTP 状态码通常为 `200`（部分写操作为 `201`/`204`）。

### 3.2 错误返回

所有错误响应均由全局异常处理器统一封装，结构如下：

```json
{
  "code": <HTTP状态码>,
  "message": "错误描述",
  "detail?": "可选的详细错误信息"
}
```

| 场景 | HTTP 状态码 | `message` | 说明 |
|------|------------|-----------|------|
| 参数校验失败 | `422` | 请求参数校验失败 | 附 `detail: [...]` 具体字段错误 |
| 业务逻辑错误 | `400` / `401` / `403` / `404` | 视具体接口而定 | 如用户名已存在、权限不足等 |
| 数据库异常 | `500` | 数据库异常，请稍后重试 | — |
| 未预料异常 | `500` | 服务器内部错误 | 兜底，不暴露堆栈 |

**示例 — 参数校验失败：**

```json
{
  "code": 422,
  "message": "请求参数校验失败",
  "detail": [
    {
      "loc": ["body", "email"],
      "msg": "value is not a valid email address",
      "type": "value_error.email"
    }
  ]
}
```

**示例 — 权限不足：**

```json
{
  "code": 403,
  "message": "权限不足，需要超级管理员权限"
}
```

## 4. 认证说明

除 `POST /api/v1/users/login`、`POST /api/v1/users/register` 和 `POST /api/v1/users/refresh-token` 外，其余接口均需在请求头中携带访问令牌：

```
Authorization: Bearer <access_token>
```

令牌失效或缺失时，返回 `401`：

```json
{
  "code": 401,
  "message": "缺少认证令牌"
}
```

## 5. 单接口详细定义

### 5.1 论坛回复管理

---

### POST `/api/v1/forum_posts/{post_id}/replies`

- **功能**：发表回复
- **认证**：登录用户

#### Path 参数

| 名称 | 类型 | 必填 | 说明 |
|------|------|------|------|
| post_id | integer | 是 | 帖子 ID |

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### RequestBody

| 名称 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| content | string | 是 | 最小 1 字符 | 回复内容（支持 Markdown；可包含内嵌图片 `![alt](url)`） |

#### 成功响应

- **状态码**：`201`
- **返回**：`ForumReplyResponse`

| 名称 | 类型 | 说明 |
|------|------|------|
| id | integer | 回复 ID |
| post_id | integer | 帖子 ID |
| content | string | 回复内容（支持 Markdown） |
| user_id | integer | 作者 ID |
| user | `UserBriefInfo` | 作者信息（id, username, avatar_url） |
| likecount | integer | 点赞数（字段名即 `likecount`，非 `like_count`） |
| comment_count | integer | 评论数 |
| created_at | string(datetime) | 创建时间 |
| is_liked | boolean | 当前登录用户是否已点赞 |

> `UserBriefInfo` 字段：id, username, avatar_url

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 401 | 缺少认证令牌 |
| 404 | 帖子不存在 |
| 422 | 请求参数校验失败 |

---

### GET `/api/v1/forum_posts/{post_id}/replies`

- **功能**：查询某帖子下的回复列表（分页）
- **认证**：登录用户

#### Path 参数

| 名称 | 类型 | 必填 | 说明 |
|------|------|------|------|
| post_id | integer | 是 | 帖子 ID |

#### Query 参数

| 名称 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| skip | integer | 否 | `≥ 0`，默认 `0` | 跳过数量 |
| limit | integer | 否 | `1~100`，默认 `20` | 返回数量上限 |

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### 成功响应

- **状态码**：`200`
- **返回**：`ForumReplyListResponse`

| 名称 | 类型 | 说明 |
|------|------|------|
| items | `ForumReplyResponse[]` | 回复列表 |
| total | integer | 符合条件的回复总数（用于分页计算） |

`ForumReplyResponse` 字段：

| 名称 | 类型 | 说明 |
|------|------|------|
| id | integer | 回复 ID |
| post_id | integer | 所属帖子 ID |
| content | string | 回复内容（Markdown） |
| user_id | integer | 作者 ID |
| user | `UserBriefInfo` | 作者信息（id, username, avatar_url） |
| likecount | integer | 点赞数（字段名即 `likecount`，非 `like_count`） |
| comment_count | integer | 评论数 |
| created_at | string(datetime) | 创建时间 |
| is_liked | boolean | 当前登录用户是否已点赞 |

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 404 | 帖子不存在 |
| 422 | 请求参数校验失败 |

---

### DELETE `/api/v1/forum_replies/{reply_id}`

- **功能**：删除回复
- **级联说明**：删除回复时会同步删除回复正文内嵌图片、该回复下评论与评论点赞记录，并递减所属帖子的回复数（`reply_count`）
- **认证**：作者本人、管理员或区主

#### Path 参数

| 名称 | 类型 | 必填 | 说明 |
|------|------|------|------|
| reply_id | integer | 是 | 回复 ID |

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### 成功响应

- **状态码**：`204`
- **返回**：无

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 404 | 回复不存在 |
| 403 | 权限不足 |

---
