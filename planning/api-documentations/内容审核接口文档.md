# 内容审核接口文档

## 1. 接口概览

### 1.1 内容审核管理

| 方法 | 路径 | 功能简述 | 认证要求 |
|------|------|---------|---------|
| GET | `/api/v1/content_moderation/records` | 查询审核记录列表 | 管理员及以上 |
| GET | `/api/v1/content_moderation/records/{id}` | 查看单条审核详情 | 管理员及以上 |
| POST | `/api/v1/content_moderation/records/{id}/retry` | 重试审核任务 | 管理员及以上 |
| GET | `/api/v1/content_moderation/stats` | 获取审核统计概览 | 管理员及以上 |
| GET | `/api/v1/content_moderation/records/export` | 导出审核记录 | 管理员及以上 |

## 2. 枚举与常量定义

| 常量/枚举 | 值 | 说明 |
|-----------|-----|------|
| 状态 `status` | `"pending"` | 待审核 |
| | `"running"` | 审核中 |
| | `"passed"` | 已通过 |
| | `"blocked"` | 已拦截（命中敏感内容并已处置） |
| | `"action_failed"` | 处置失败 |
| | `"review_failed"` | 审核失败（LLM 调用或解析异常） |
| | `"stale"` | 已过期（目标内容在审核期间被更新） |
| 目标类型 `target_type` | `"user"` | 用户资料 |
| | `"blog_post"` | 博客文章 |
| | `"forum_zone"` | 论坛分区 |
| | `"forum_post"` | 论坛帖子 |
| | `"forum_reply"` | 论坛回复 |
| | `"comment"` | 评论 |
| 风险等级 `risk_level` | `"none"` | 无风险 |
| | `"low"` | 低风险 |
| | `"medium"` | 中风险 |
| | `"high"` | 高风险 |
| 触发动作 `trigger_action` | `"create"` / `"update"` / `"publish"` / `"retry"` | 触发审核的业务动作 |
| 默认分页 | `skip=0, limit=20` | 列表接口默认值，`limit` 上限 `100` |
| 导出上限 | `limit=10000` | 导出接口单次上限 |

## 3. 统一封装返回结果

### 3.1 成功返回

后端**未**对成功响应做统一封装。接口成功时，直接返回对应 Schema 序列化后的 JSON，HTTP 状态码通常为 `200`。

### 3.2 错误返回

所有错误响应均由全局异常处理器统一封装，结构如下：

```json
{
  "code": <HTTP状态码>,
  "message": "错误描述",
  "detail?": "可选的详细错误信息"
}
```

| 场景 | HTTP 状态码 | `message` | 说明 |
|------|------------|-----------|------|
| 参数校验失败 | `422` | 请求参数校验失败 | 附 `detail: [...]` 具体字段错误 |
| 未认证 | `401` | 缺少认证令牌 / 令牌校验失败 | — |
| 权限不足 | `403` | 权限不足 | 非管理员访问 |
| 记录不存在 | `404` | 审核记录不存在 | — |
| 状态不允许重试 | `400` | 记录状态不允许重试: xxx | 仅 `review_failed`/`action_failed`/`stale` 可重试 |
| 未预料异常 | `500` | 服务器内部错误 | 兜底，不暴露堆栈 |

---

## 4. 认证说明

所有接口均需在请求头中携带访问令牌：

```
Authorization: Bearer <access_token>
```

令牌失效或缺失时，返回 `401`：

```json
{
  "code": 401,
  "message": "缺少认证令牌"
}
```

**权限要求**：所有内容审核接口均要求当前用户为**管理员及以上**（`permission ≥ 1`）。普通用户调用将返回 `403`。

## 6. 单接口详细定义

### 6.1 审核记录列表

---

### GET `/api/v1/content_moderation/records`

- **功能**：分页查询内容审核记录，支持多维筛选
- **认证**：管理员及以上（`permission ≥ 1`）

#### Query 参数

| 名称 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| skip | integer | 否 | `≥ 0`，默认 `0` | 跳过数量 |
| limit | integer | 否 | `1~100`，默认 `20` | 返回数量上限 |
| status | string | 否 | 见状态枚举 | 按审核状态筛选 |
| target_type | string | 否 | 见目标类型枚举 | 按对象类型筛选 |
| risk_level | string | 否 | 见风险等级枚举 | 按风险等级筛选 |
| user_id | integer | 否 | `≥ 1` | 按触发用户筛选 |
| start_time | string(datetime) | 否 | ISO 8601 格式 | 创建时间起始（含） |
| end_time | string(datetime) | 否 | ISO 8601 格式 | 创建时间截止（含） |

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### 成功响应

- **状态码**：`200`
- **返回**：`ContentModerationRecordListResponse`

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 403 | 权限不足 |
| 422 | 请求参数校验失败（如非法的 status/target_type/risk_level） |

---

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

- **状态码**：`200`

#### 失败响应

### 6.3 重试审核

---

### POST `/api/v1/content_moderation/records/{id}/retry`

- **功能**：对失败的审核记录进行重试。重置状态为 `pending` 并重新调度后台任务
- **认证**：管理员及以上（`permission ≥ 1`）

#### Path 参数

| 名称 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | integer | 是 | 审核记录 ID |

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### 成功响应

- **状态码**：`200`
- **返回**：`ContentModerationRetryResponse`

```json
{
  "id": 42,
  "task_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "status": "pending",
  "message": "审核任务已重新调度"
}
```

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 404 | 审核记录不存在 |
| 400 | 记录状态不允许重试（仅 `review_failed`/`action_failed`/`stale` 可重试） |
| 403 | 权限不足 |

### 6.5 数据导出

---

### GET `/api/v1/content_moderation/records/export`

- **功能**：导出审核记录数据为 JSON 或 CSV
- **认证**：管理员及以上（`permission ≥ 1`）

#### Query 参数

| 名称 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| format | string | 否 | `json`/`csv`，默认 `json` | 导出格式 |
| status | string | 否 | 见状态枚举 | 筛选条件 |
| target_type | string | 否 | 见目标类型枚举 | 筛选条件 |
| risk_level | string | 否 | 见风险等级枚举 | 筛选条件 |
| user_id | integer | 否 | `≥ 1` | 筛选条件 |
| start_time | string(datetime) | 否 | ISO 8601 | 筛选条件 |
| end_time | string(datetime) | 否 | ISO 8601 | 筛选条件 |

#### Headers

| 名称 | 必填 | 说明 |
|------|------|------|
| Authorization | 是 | `Bearer <access_token>` |

#### 成功响应

- **状态码**：`200`
- **Content-Type**：`application/json` 或 `text/csv; charset=utf-8`
- **Content-Disposition**：`attachment; filename="content_moderation_YYYYMMDD_HHMMSS.{json|csv}"`

JSON 格式示例：

```json
[
  {
    "id": 1,
    "task_id": "...",
    "trace_id": "cm-...",
    "target_type": "blog_post",
    "target_id": 42,
    "status": "blocked",
    ...
  }
]
```

#### 失败响应

| 状态码 | 原因 |
|--------|------|
| 403 | 权限不足 |
| 422 | 非法的 format 或其他参数 |
