## 六、发现的问题

### 6.1 ⚠️ 中低风险问题

| # | 问题描述 | 影响 | 建议 |
|---|---------|------|------|
| 1 | 博客详情页评论数显示为 0，但实际有 1 条评论 | 用户感知 | 可能是 `comment_count` 字段未正确更新或前端显示的是另一个计数 |
| 2 | Windows 环境下通过 curl 发送中文 JSON 时，后端接收为乱码 | 开发体验 | 建议统一使用 UTF-8 编码，或使用 Python requests 替代 curl |
| 3 | 首页博客/论坛区块在无数据时完全隐藏，用户可能误以为功能不可用 | 用户体验 | 建议空状态展示提示文案而非完全隐藏区块 |
| 4 | 博客更新接口（PUT）在直接 API 测试中返回 422 | 待确认 | 更新接口要求 `multipart/form-data` + `post_in` JSON 字符串，测试调用方式可能需要调整；需确认前端是否正常 |

### 6.2 ✅ 已验证的正确行为

- 三角色权限隔离严格，越权操作均被正确拒绝
- Token 机制完善，登出/改密码后旧 Token 失效
- 前端路由守卫（AuthGuard）有效拦截未授权访问
- 所有 API 错误均通过全局异常处理器统一封装返回
- Markdown 渲染、图片上传、OSS 存储均正常工作
